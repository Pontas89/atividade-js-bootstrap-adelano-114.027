# Painel de Estudos

## 1. Nome e tema do projeto

O projeto se chama Painel de Estudos e tem como tema a organização da rotina acadêmica. Ele foi desenvolvido para praticar os conceitos iniciais de JavaScript ES6 e Bootstrap.

## 2. Explicação da interface

A interface apresenta informações sobre tarefas, notas e organização dos estudos. O objetivo é criar uma tela simples e organizada para representar um painel acadêmico.

## 3. Componentes Bootstrap utilizados

Foram utilizados os seguintes componentes e classes do Bootstrap:

- Navbar: barra de navegação com o nome do projeto.
- Container: organiza o conteúdo da página.
- Row e Col: organizam os elementos em linhas e colunas responsivas.
- Card: apresenta informações sobre tarefas, notas e organização.
- Badge: indica o status de cada seção.
- Button: apresenta um botão visual.
- Alert: exibe uma dica para os estudos.
- Footer: apresenta o rodapé da página.

O Bootstrap foi conectado pelo CDN, sem a necessidade de criar um arquivo CSS próprio.

## 4. Diferença entre let, const e var

A declaração const é utilizada para variáveis que não precisam receber uma nova atribuição. No projeto, ela foi utilizada para guardar o nome do aluno, o curso e as notas.

A declaração let é utilizada quando o valor de uma variável pode mudar. No projeto, ela foi utilizada para alterar a quantidade de tarefas e materiais.

A declaração var é uma forma antiga de declarar variáveis em JavaScript. Atualmente, let e const são priorizados porque possuem escopo mais previsível e ajudam a evitar alguns problemas comuns.

## 5. Tipos de dados utilizados

- String: texto, como o nome do curso.
- Number: números, como as notas e os preços.
- Boolean: valor verdadeiro ou falso, como o estado do painel.
- Null: representa a ausência intencional de um valor.

## 6. Condição com if e else

Foi criada uma condição para verificar se a média do aluno é maior ou igual a 6.

Se a média for maior ou igual a 6, o programa exibe uma mensagem de aprovação. Caso contrário, exibe uma mensagem informando que o aluno precisa revisar o conteúdo.

Também foi criada uma condição para verificar se o valor do material de estudo, após o desconto, atinge o mínimo de R$ 40 para obter frete grátis.

## 7. Cálculos e template literals

O JavaScript realiza operações de soma, subtração, multiplicação e divisão. Também calcula a média das notas e o valor final de um pedido.

Os template literals foram utilizados para montar mensagens com informações armazenadas em variáveis, utilizando a sintaxe ${}.

## 8. Maior dificuldade encontrada

Minha maior dificuldade foi compreender como conectar o arquivo JavaScript ao HTML e entender a diferença entre let, const e var.

## 9. Como a dificuldade foi resolvida

A dificuldade foi resolvida consultando os exemplos da atividade, organizando o código em etapas e verificando os resultados exibidos no Console do navegador.

## 10. Conclusão

A atividade permitiu praticar os conceitos básicos de JavaScript ES6 e conhecer componentes do Bootstrap para construir uma interface responsiva. Também foi possível compreender a importância de organizar os arquivos de um projeto e publicá-los no GitHub.
